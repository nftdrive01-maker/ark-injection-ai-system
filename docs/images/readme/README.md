# README image slots

This directory holds the visual assets used by the repository README.

- `hero-lp.png`
- `amica-ui.png`
- `admin-knowledge.png`
- `amica-hero-placeholder.svg`

Recommended replacement flow:

1. Export screenshots in 16:9 or wide desktop ratio.
2. Replace the current PNG assets or update the paths in the repository root `README.md`.
3. Hide secrets, local URLs, OAuth tokens, and private domain names before committing.

Recommended captures:
